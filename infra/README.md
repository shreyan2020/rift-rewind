# Archived AWS prototype

The active application uses the FastAPI backend in [`../backend/`](../backend/) and local JSON storage. This directory preserves the earlier AWS implementation and is not required for the local app.

The original pipeline used API Gateway, Lambda, SQS, DynamoDB, S3, and Bedrock. Its source and template remain for reference. Historical deployment instructions are available in Git history.

Use the [root README](../README.md) to run the current application.
